# 整理只改变显示归属，永不移动用户文件

整理由 AI 决定每个桌面项显示在哪个分区里，但文件在磁盘上原地不动。deskmind 不移动、不重命名、不删除用户的任何文件。这是一条产品承诺，不只是实现选择。

## Considered Options

让 AI 真的把文件移进对应文件夹，看上去是"更彻底"的整理。拒绝的理由是出错代价严重不对称：只改显示归属时，AI 分错了用户拖一下就好，风险为零；真移动文件时，AI 分错了就是用户的文件不见了，找回来要翻回收站和日志，而用户会立刻卸载并且不再信任产品。

这个不对称还有一个非显然的连锁反应：因为只改显示零风险，AI 可以自动、静默地运行，体验是「桌面自己就整齐了」；而真移动文件出于安全必须每次弹确认框，反而比用户手动拖拽还要烦。**不动文件不仅更安全，产品体验也更好。**

Fences 类产品全程只做视觉分组，卖了十几年，说明这个模式已经足够解决痛点。

## Consequences

这是一条信任承诺，立了之后几乎不可能收回——一旦对外说过「我们不碰你的文件」，后续版本再加入移动文件的功能会被视为背叛。任何未来涉及写用户文件的功能，都必须重新审视这条 ADR。
