# 美化为主线，AI 为差异化能力

> **Status**: 由 ADR-0013 修订——定位不变，v1 的载体改为全屏启动台。

deskmind 定位为「带 AI 的桌面美化软件」，而不是「长得好看的 AI 桌面助手」。选择前者，是因为「桌面美化」有可验证的搜索量和已被同类产品证明过的付费意愿，而「AI 桌面助手」的正面竞争对手是拥有系统级权限与预装渠道的微软。

这条定位同时给出了 AI 功能的取舍标准：只做那些没有 AI 就做不出来的功能。凡是规则引擎能完成的（按时间换壁纸、按扩展名归类），一律不挂 AI。

## Consequences

v1 面向 GitHub 上愿意折腾的发烧友，不做大众消费级分发。这允许我们暂时接受更大的安装包、更少的兼容性打磨、以及没有客服体系，把成本集中在验证「AI 整理桌面是不是真需求」这一个假设上。

该假设验证成立后，再考虑向消费级升级。届时安装包体积、多显示器与 DPI 兼容性、杀软误报会重新变成一等问题。
