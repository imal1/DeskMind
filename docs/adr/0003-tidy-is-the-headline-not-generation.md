# 以「AI 整理」为主打，生成类功能降级到 v2

deskmind 的一句话命题是「会自己整理的桌面」。AI 生成壁纸、自动配色、成套主题这些功能推迟到 v2，不作为 v1 的主打。

## Considered Options

生成类功能（一句话出壁纸、从壁纸提取配色）视觉冲击力最强、最容易传播，看上去是更好的主打。拒绝它的理由有两条：它的竞争对手是所有 AI 出图工具，我们在生成质量上没有任何优势；而且它是一次性体验，用户玩两三次就腻，撑不起留存。

「情境感知的场景切换」同样被否，原因是新用户对它零感知——做出来没人知道好在哪。

整理之所以胜出，是因为它是唯一一个「已被同类产品验证为真需求、且 AI 明显能比现有方案做得更好」的方向。Fences 类产品卖了十几年，其用户最大的抱怨恰恰是必须手动拖拽、手动配置规则，那正是 AI 的位置。这个痛点也和 v1 的目标用户（桌面很乱、又讨厌配规则的发烧友）精准重合。

## Consequences

生成类功能保留为 v2 的获客钩子，但不进 v1 范围，也不写进 README 第一句话。
